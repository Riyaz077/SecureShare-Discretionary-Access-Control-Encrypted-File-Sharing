# Project Overview

**Title:** SecureShare: Development of a Secure File Management System Using Discretionary Access Control, Cryptography, and Security Auditing

**Core problem:** Unauthorized access to confidential files caused by weak or unclear file-sharing permissions.

**Proposed solution:** A web-based file-sharing system in which file owners manage user-specific permissions, files are encrypted at rest, and important access events are recorded for review.

**Primary outcome:** Demonstrate a practical implementation of DAC and cryptographic protection using Python.

**Important scope statement:** The application demonstrates the DAC and cryptography topic from the internship certificate. It is an independently developed portfolio project and should not be represented as the exact deliverable completed during the 2023 internship.
